# Инструкция по установке и запуску SOS App

## Быстрый старт

### 1. Проверьте установку Flutter
```bash
flutter doctor
```

### 2. Установите зависимости
```bash
cd sos_app
flutter pub get
```

### 3. Запустите приложение
```bash
# Убедитесь, что устройство/эмулятор подключен
flutter devices

# Запустите приложение
flutter run
```

## Тестирование функций

### Активация SOS:
1. Нажмите большую красную кнопку SOS
2. ИЛИ встряхните устройство (на реальном устройстве)

### Настройки:
1. Нажмите иконку шестеренки в правом верхнем углу
2. Добавьте экстренные контакты
3. Измените чувствительность встряхивания

### История:
1. Нажмите иконку часов в правом верхнем углу
2. Просмотрите историю активаций SOS

## Возможные проблемы

### На Android:
- Если не работают разрешения, перейдите в Настройки > Приложения > SOS App > Разрешения
- Убедитесь, что GPS включен

### На iOS:
- При первом запуске согласитесь на все запросы разрешений
- Проверьте настройки конфиденциальности в iOS

### На эмуляторе:
- Функция встряхивания может не работать на эмуляторе
- GPS может показывать фиктивные координаты
- Камера/микрофон могут быть недоступны

## Сборка релиза

### Android APK:
```bash
flutter build apk --release
# Файл будет в: build/app/outputs/flutter-apk/app-release.apk
```

### iOS:
```bash
flutter build ios --release
# Требует настройку подписи в Xcode
```
