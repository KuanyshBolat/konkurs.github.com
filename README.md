# Lemocode - Corporate IT Company Website

A modern, responsive corporate website for Lemocode IT company, specializing in IT solutions for small and medium businesses (SMB).

## 🚀 Features

### Design & UX
- **Dark Theme**: Modern dark design with neon-green (#00FF85) and yellow (#FFD600) accents
- **Responsive Design**: Fully responsive across all devices and screen sizes
- **Modern Animations**: Smooth scroll animations, hover effects, and micro-interactions
- **Professional Typography**: Inter font family for clean, modern appearance

### Pages Implemented
- ✅ **Homepage** (`index.html`) - Hero section, services overview, advantages, portfolio preview
- ✅ **Services** (`services.html`) - Detailed service descriptions with interactive tabs
- ✅ **Contacts** (`contacts.html`) - Contact forms, company info, FAQ, map integration
- 🚧 **Portfolio** (`portfolio.html`) - Project showcase with filtering (planned)
- 🚧 **About** (`about.html`) - Company information and team (planned)
- 🚧 **Blog** (`blog.html`) - Knowledge base and articles (planned)

### Key Features
- **Interactive Service Tabs**: Smooth transitions between service categories
- **Advanced Form Handling**: Real-time validation, phone masking, success modals
- **FAQ Accordion**: Expandable FAQ section with smooth animations
- **Contact Forms**: Multiple contact forms with different purposes
- **Mobile Navigation**: Hamburger menu with smooth animations
- **Scroll Effects**: Parallax effects and scroll-triggered animations
- **Performance Optimized**: Efficient code with minimal dependencies

## 🛠 Technology Stack

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Modern CSS with CSS Grid, Flexbox, and CSS Variables
- **Vanilla JavaScript**: No external dependencies, pure ES6+
- **SVG Icons**: Scalable vector icons for crisp display
- **Google Fonts**: Inter font family integration

## 🎨 Design System

### Color Palette
- **Primary Background**: `#121212` (Dark)
- **Secondary Background**: `#1e1e1e` (Lighter dark)
- **Tertiary Background**: `#2a2a2a` (Cards/sections)
- **Accent Green**: `#00FF85` (Primary accent)
- **Accent Green Hover**: `#2EFFB1` (Hover state)
- **Accent Yellow**: `#FFD600` (Secondary accent)
- **Accent Yellow Hover**: `#FFF200` (Hover state)
- **Primary Text**: `#ffffff` (White)
- **Secondary Text**: `#b3b3b3` (Gray)
- **Dark Text**: `#333333` (For light backgrounds)

### Typography
- **Font Family**: Inter (Google Fonts)
- **Weights**: 300, 400, 500, 600, 700
- **Scale**: Consistent typography scale using CSS variables

### Spacing
- Consistent spacing system using CSS variables
- 8px base unit with multipliers

```css

    --accent-green: #00FF85;
    --accent-yellow: #FFD600;
    /* ... other variables */
}
```

- Update text content in HTML files
- Replace placeholder contact information
- Customize service descriptions

### Forms
- Connect forms to your backend API
- Update form action endpoints in JavaScript files
