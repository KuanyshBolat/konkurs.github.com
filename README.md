# SOS Emergency App

Мобильное приложение экстренных вызовов, переделанное с React на Flutter.

## Функциональность

### Основные возможности:
- **SOS-кнопка**: Большая красная кнопка для активации экстренного вызова
- **Определение встряхивания**: Автоматическая активация при встряхивании устройства
- **Запись видео и аудио**: Автоматическая запись 15-секундного видео/аудио при активации
- **GPS-местоположение**: Определение и отправка координат
- **Управление контактами**: Добавление/удаление экстренных контактов
- **История вызовов**: Просмотр истории всех экстренных активаций
- **Настройки чувствительности**: Регулировка чувствительности определения встряхивания

### Экраны приложения:
1. **Главный экран** - SOS-кнопка и индикаторы статуса
2. **Настройки** - Управление контактами и чувствительностью
3. **История** - Список всех экстренных вызовов

## Разрешения

### Android:
- `CAMERA` - для записи видео
- `RECORD_AUDIO` - для записи аудио
- `ACCESS_FINE_LOCATION` - для определения GPS
- `ACCESS_COARSE_LOCATION` - для определения GPS
- `WRITE_EXTERNAL_STORAGE` - для сохранения записей
- `INTERNET` - для отправки данных
- `VIBRATE` - для вибрации

### iOS:
- `NSCameraUsageDescription` - доступ к камере
- `NSMicrophoneUsageDescription` - доступ к микрофону
- `NSLocationWhenInUseUsageDescription` - доступ к местоположению
- `NSMotionUsageDescription` - доступ к датчикам движения

## Использование

### Активация экстренного вызова:
1. **Нажатие кнопки**: Нажмите большую красную SOS-кнопку
2. **Встряхивание**: Интенсивно встряхните устройство

### При активации происходит:
1. Экран мигает красным 3 раза
2. Воспроизводится звуковой сигнал
3. Начинается запись видео и аудио (15 сек)
4. Определяется текущее местоположение
5. Данные отправляются в Guard Me
6. Запись добавляется в историю

### Настройка чувствительности:
- **Низкая**: Требуется сильное встряхивание
- **Средняя**: Стандартная чувствительность (по умолчанию)
- **Высокая**: Активация при легком движении

## Безопасность

- Все записи сохраняются локально на устройстве
- GPS-координаты передаются только при активации
- Контакты хранятся в зашифрованном виде
- Приложение работает в фоновом режиме для быстрой активации
